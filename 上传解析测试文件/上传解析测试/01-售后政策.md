# 商城售后政策（上传解析测试）

本资料为教学模拟政策，用于对比不同格式文件的文字提取结果。

## 一、七天无理由退货

签收后七天内，可以申请无理由退货。商品须保持完好，配件齐全。
已拆封且影响二次销售的商品，不适用七天无理由退货。质量问题另按售后规则处理。

## 二、申请材料

申请时需要提供订单号、商品照片和问题说明。审核通过后，按客服提供的地址寄回。

## 三、质量问题

商品出现质量问题时，请提交故障描述及照片或视频，由售后核实处理。保修期限以对应商品的保修说明为准。

## 四、规则速查表

| 事项 | 条件或说明 |
| --- | --- |
| 退货时限 | 签收后七天内 |
| 商品状态 | 商品完好，配件齐全 |
| 拆封例外 | 已拆封且影响二次销售，不适用无理由退货 |
| 退款到账 | 以支付渠道实际处理为准，未承诺固定天数 |

核对标记：解析完成后应能看到这句话。
